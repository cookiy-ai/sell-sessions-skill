# Sell Your AI Agent Sessions

Your Codex, Claude Code, and other AI agent sessions can be valuable to AI labs improving their products. Cookiy Earn helps you license the sessions you choose and get paid each time they sell to a buyer.

## How It Works

1. Choose which agent sessions you want to sell.
2. The local uploader strips detected secrets and PII on your machine, then estimates each session's value before upload.
3. Cookiy Earn matches your sessions with potential buyers and pays you for each completed sale.

## How to Use

### Approach 1: Install the skill

```sh
npx skills add cookiy-ai/sell-sessions-skill --global
```

Then tell your AI agent:

> I want to sell agent sessions data to earn income.

### Approach 2: Ask your AI agent to install it

Paste this into your AI agent:

> Follow https://github.com/cookiy-ai/sell-sessions-skill to install the skill and start the local session uploader for me.
